# 4.6 Actividades con Objetos

## Autor
Christian Said Jimenez Mahecha

## Estructura del proyecto

```
4.6-Actividades-con-objetos
│
├── ejercicios
│   ├── ejercicios.js
│   └── index.html
│
├── .gitignore
└── README.md
```

## Contenido

### ejercicios.js

Contiene las soluciones de los ejercicios:

- 1. Creación y acceso a objetos
- 2. Bucle ForEach
- 3. Referencias de objetos y clonación
- 4. Métodos en objetos y uso de this
- 5. Symbol y claves ocultas
- 6. Conversión de objetos a valores primitivos
- 7. Herencia de clases
- 8. Encapsulación con propiedades privadas

### index.html

Contiene la práctica del ejercicio 10:

- DOM
- Eventos
- window.alert()
- window.open()
- postMessage()
- setTimeout()

## Ejecución

### Ejercicios 1 al 8

Abrir:

```
ejercicios/ejercicios.js
```

y ejecutarlo con Node.js:

```bash
node ejercicios.js
```

### Ejercicio 10

Abrir:

```
ejercicios/index.html
```

directamente en el navegador.
